# Bundled assets

The meal and environment images are local copies of the images in the team's
supplied Stitch HTML designs. They illustrate sample entries and are not
photographs of real user logs.

Outfit and Hanken Grotesk are from the Google Fonts repository and distributed
under the SIL Open Font License. Their license files are bundled next to the
fonts and available through Flutter's license registry. No runtime font or
image downloads are needed.
